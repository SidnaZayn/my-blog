# My Personal Portfolio

This is a personal portfolio website built with Astro, Vue.js, and Tailwind CSS. It showcases my work experience, projects, and provides a way to contact me.

## Features

*   **Modern Tech Stack:** Built with Astro for optimal performance, Vue.js for interactive UI components, and Tailwind CSS for utility-first styling.
*   **Fast & Performant:** Leverages Astro's island architecture for fast loading times and an excellent user experience.
*   **MDX Support:** Content can be written using MDX, allowing for dynamic and interactive components within markdown.
*   **Responsive Design:** Ensures a seamless experience across various devices and screen sizes using Tailwind CSS.
*   **Accessibility Focused:** Built with accessibility in mind, utilizing `accessible-astro-components`.
*   **Animations:** Includes engaging animations powered by `animejs` and dynamic text effects with `typed.js`.
*   **Icon Management:** Easy integration of icons using `astro-icon` and `@iconify/vue`.
*   **Optimized Deployment:** Configured for efficient deployment on platforms like Netlify.

## Technologies Used

*   **Astro:** Web framework for building fast, content-focused websites.
*   **Vue.js:** Progressive JavaScript framework for building user interfaces.
*   **Tailwind CSS:** A utility-first CSS framework for rapidly building custom designs.
*   **Sass:** CSS pre-processor for enhanced styling capabilities.
*   **MDX:** Allows you to write JSX in your Markdown documents.
*   **Netlify:** Platform for automated web projects.
*   **@astrojs/partytown:** For optimizing third-party scripts.
*   **astro-icon & @iconify/vue:** For SVG icon management.
*   **accessible-astro-components:** Accessible UI components for Astro.
*   **animejs:** Lightweight JavaScript animation library.
*   **typed.js:** A JavaScript typing animation library.
